DIAGNOSTICS & QA

Utilizing 1M token context windows for full-repository bug hunting and stack trace analysis.
🔍
1. Gemini Studio
  • Access Google AI Studio with the unified corporate account.
  • Create a reusable prompt template named "Repo Audit".
  • Keep a local ZIP of the GitHub repository handy for rapid uploads.
🐛
2. The Debug Loop
  • When GitHub Actions fails, download the terminal build logs.
  • Drop the logs AND the entire repo ZIP into Gemini's 1M token window.
  • Prompt: "Find the exact syntax error causing this build failure."
🛠️
3. Resolution Sync
  • Copy the isolated code fix provided by Gemini.
  • Feed the corrected code back into Bolt.new or Qwen to apply the patch.
  • Log the post-mortem in the #gemini-diagnostics Discord channel.
